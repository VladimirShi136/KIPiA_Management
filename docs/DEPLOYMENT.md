## 📋 Обзор

Этот документ описывает два способа развертывания приложения **KIPiA Management System**:
1. **Стандартный** - сборка и запуск JAR-файла
2. **Расширенный** - создание исполняемого EXE-установщика для Windows с помощью Inno Setup

---

## ⚙️ 1. Предварительные требования

### Для обоих способов:
* **Java JDK 23** или выше
* **Apache Maven 3.9+**

### Только для EXE-установщика:
* **ОС Windows**
* Установленный **[Inno Setup 6](https://jrsoftware.org/isinfo.php)**
    * По умолчанию ожидается в `C:\Program Files (x86)\Inno Setup 6\ISCC.exe`
    * При установке в другое место - измените путь в `compile-inno-setup.bat`
* **JavaFX SDK 25.0.1** - распакуйте в `C:\javafx-sdk-25.0.1\`
* Скрипты автоматизации из папки `KIPiA_Management\`

**Важно:** EXE установщик требует установленной Java 23+. Java Runtime в установщик не включена.

## 📦 2. Стандартное развертывание (JAR-файл)

Этот метод создает переносимый `.jar` файл, который можно запустить в любой системе с установленной Java.

### 2.1 Сборка проекта

Выполните из корневой папки проекта:

```bash
mvn clean package
```

После успешной сборки исполняемый JAR-файл будет создан в папке target/ с именем вида `KIPiA_Management-{версия}.jar`.


### 2.2 Запуск приложения

Для запуска используйте команду:

```bash
java --module-path "PATH_TO_JAVAFX_SDK\lib" ^
     --add-modules javafx.controls,javafx.fxml,javafx.graphics,javafx.base ^
     -jar target\KIPiA_Management-*.jar
```

ℹ️ Примечание: Замените `PATH_TO_JAVAFX_SDK` на путь к вашему JavaFX SDK.

## 📦 3. Создание EXE-установщика для Windows

В проекте предусмотрена возможность сборки профессионального установщика с помощью Inno Setup.

### 3.1 Подготовка и структура скриптов

В проекте доступны следующие скрипты в папке `KIPiA_Management/`:

| Скрипт                         | Назначение                                                     |
|--------------------------------|----------------------------------------------------------------|
| build-exe-installer.bat        | Главный скрипт, запускающий весь процесс сборки EXE           |
| create-installer-structure.bat | Создает структуру папок установщика и копирует файлы           |
| generate-iss.ps1               | Генерирует ISS-файл конфигурации с версией из pom.xml          |
| compile-inno-setup.bat         | Компилирует ISS-файл через Inno Setup                         |

### 3.2 Управление версией

Версия приложения определяется в одном месте - в файле `pom.xml`:

```xml
<version>2.1.1</version>
```

При запуске `build-exe-installer.bat` версия автоматически:
- Читается из `pom.xml` через PowerShell
- Подставляется в имя JAR-файла
- Подставляется в ISS-файл конфигурации
- Используется в имени итогового EXE-файла

Для изменения версии приложения отредактируйте только строку `<version>` в `pom.xml`.

### 3.3 Процесс сборки установщика

Процесс полностью автоматизирован. Запустите из корня проекта:

```batch
build-exe-installer.bat
```

Скрипт выполняет следующие шаги:

1. **Очистка** - удаляет папки `KIPiA_Installer` и `Output`
2. **Сборка JAR** - выполняет `mvn clean package`
3. **Чтение версии** - извлекает версию из `pom.xml`
4. **Создание структуры** - запускает `create-installer-structure.bat`
   - Копирует JAR в `KIPiA_Installer/`
   - Копирует зависимости в `KIPiA_Installer/dependencies/`
   - Копирует JavaFX SDK из `C:\javafx-sdk-25.0.1\`
   - Копирует ресурсы (log4j2.xml, README, ChangeLog)
   - Создает лаунчер `KIPiA_Management.exe.bat`
5. **Генерация ISS** - запускает `generate-iss.ps1` с версией из pom.xml
6. **Компиляция EXE** - запускает `compile-inno-setup.bat`

### 3.4 Результат сборки

После успешного выполнения в папке `Output\` появится файл:
```
KIPiA_Management_2.1.1.exe
```

Имя файла включает версию приложения из `pom.xml`.

## 🔄 4. Сравнение методов развертывания

| Метод          | Преимущества                                                    | Недостатки                                              | Целевая аудитория                      |
|----------------|-----------------------------------------------------------------|---------------------------------------------------------|----------------------------------------|
| JAR-файл       | Кросс-платформенность, простая сборка                           | Требует установленной JRE                               | Разработчики, технические пользователи |
| EXE-установщик | Нативная установка в Windows, создание ярлыков, запись в реестр | Только для Windows, требует дополнительных инструментов | Конечные пользователи Windows<br/>     |

## ❗ 5. Устранение неполадок

Распространенные проблемы и решения:

| Проблема                      | Причина	                                        | Решение                                                                      |
|-------------------------------|-------------------------------------------------|------------------------------------------------------------------------------|
| 'iscc' is not recognized      | Inno Setup не установлен или не в стандартном пути | Установите Inno Setup или измените путь в `compile-inno-setup.bat` (строка 13) |
| Ошибки при сборке JAR         | Не установлены JDK или Maven                    | Проверьте наличие JDK 23+ и Maven 3.9+, выполнив `mvn --version`            |
| JavaFX not found              | JavaFX SDK не найден в `C:\javafx-sdk-25.0.1\`  | Распакуйте JavaFX SDK 25.0.1 в указанную папку или измените путь в `create-installer-structure.bat` (строка 46) |
| Version not found             | Не удалось прочитать версию из pom.xml           | Проверьте наличие тега `<version>` в `pom.xml`                               |
| Проблемы со скриптами         | Недостаточно прав для записи                    | Запускайте .bat файлы от имени администратора                                |
| Файл установщика не создается | Ошибки в ISS-скрипте                            | Проверьте логи в консоли и исправьте файл `installer_resources\KIPiA_Setup.iss` |

## 💡 6. Настройка установщика

### Изменение параметров установки

Если вам нужно внести изменения в параметры установки, отредактируйте файл `installer_resources\KIPiA_Setup.iss`:

```innosetup
[Setup]
AppName=KIPiA Management System      ; Имя приложения
AppVersion={#MyAppVersion}          ; Версия (автоматически из pom.xml)
DefaultDirName={pf}\KIPiA_Management ; Путь установки
DefaultGroupName=KIPiA Management    ; Имя группы в меню "Пуск"
```

⚠️ **Важно:** Параметр `AppVersion` теперь генерируется автоматически через `generate-iss.ps1` из `pom.xml`. Не изменяйте его вручную в ISS-файле.

Основные параметры для изменения:
* AppName - название приложения в установщике
* DefaultDirName - путь установки по умолчанию
* DefaultGroupName - имя группы в меню "Пуск"
* OutputBaseFilename - имя итогового EXE-файла (без расширения)

### Изменение путей к зависимостям

Если JavaFX SDK или Inno Setup установлены в нестандартные места:

1. **JavaFX SDK:** измените путь в `create-installer-structure.bat` (строка 46)
2. **Inno Setup:** измените путь в `compile-inno-setup.bat` (строка 13)

## 🎯 7. Рекомендации

1. Для тестирования используйте JAR-файл - это быстрее и проще
2. Для распространения среди конечных пользователей создавайте EXE-установщик
3. Перед выпуском новой версии:
   - Измените версию в `pom.xml`
   - Обновите `ChangeLog.txt` в `installer_resources/`
   - Проверьте сборку обоими способами
4. Храните резервные копии оригинального setup.iss перед внесением изменений
5. После изменения версии запустите полную сборку через `build-exe-installer.bat`
